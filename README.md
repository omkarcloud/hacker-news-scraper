## 🚀 Unlimited Free Hacker News Data — Get It in 60 Seconds

## 📚 Endpoints

13 endpoints cover everything you need.

| Endpoint | Path | Returns |
|---|---|---|
| Story Details | `/stories/details` | Any story, job or poll, with its author and poll options |
| Search Stories | `/stories/search` | 4M+ stories by keyword, type, date, points, author or site |
| Top, New & Best Stories | `/stories/list` | The front page, new, best, Ask HN, Show HN and jobs |
| Past Front Pages | `/stories/past` | The front page of any day since 2007, ranked |
| Story Comments | `/stories/comments` | A story's whole comment thread, nested, in the site's order |
| Bulk Items | `/stories/batch` | Up to 1,000 stories, comments, jobs and polls per call |
| Search Comments / Comment Details | `/comments/search`, `/comments/details` | 35M+ comments by keyword, author, story or date; one with its replies |
| User Details | `/users/details` | Karma, about text, links, submission count and join date |
| User Stories / Comments | `/users/stories`, `/users/comments` | A user's stories and comments, newest first |
| Who Is Hiring Posts | `/jobs/search` | Monthly hiring posts with headline, full text, emails and links |
| Latest Changes | `/items/updates` | The items and users that just changed, plus the newest id |

On a broad search, `count` in the answer is an estimate. `/stories/past` reads the site's own page, one request a second.
